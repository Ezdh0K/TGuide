# TGuide

TGuide — мобильное приложение-справочник по организациям, достопримечательностям и интересным местам Тюмени.

Приложение позволяет находить места по названию и категориям, использовать фильтры, просматривать подробную информацию, регистрироваться и работать с профилем пользователя.

## Возможности

* просмотр организаций и достопримечательностей;
* поиск мест по названию;
* фильтрация и разделение по категориям;
* просмотр подробной информации о месте;
* регистрация и авторизация пользователей;
* сохранение авторизации на устройстве;
* работа с профилем пользователя;
* получение данных через REST API.

## Технологии

## Установка и запуск приложения

### Для пользователей

Для использования TGuide не требуется устанавливать Node.js, Expo или самостоятельно запускать сервер.

Мобильное приложение можно установить на Android с помощью готового APK-файла.

1. Скачайте APK-файл:

   [Скачать TGuide для Android](https://github.com/Ezdh0K/TGuide/releases/download/v1.0.0/TGuide_v1.0.0.apk)

2. Откройте скачанный файл на Android-устройстве.

3. Разрешите установку приложений из сторонних источников, если система запросит разрешение.

4. Установите приложение.

5. Запустите TGuide через значок приложения.

Серверная часть приложения и база данных уже развёрнуты в интернете. После установки приложение автоматически подключается к удалённому серверу.

> Для работы приложения требуется подключение к интернету.

## Запуск проекта для разработки

Этот раздел предназначен для разработчиков, которые хотят изучить исходный код, изменить приложение или продолжить его разработку.

### Требования

Перед запуском необходимо установить:

* [Node.js](https://nodejs.org/);
* npm;
* Git;
* Expo Go на мобильное устройство или Android Emulator.

### 1. Клонирование репозитория

```bash
git clone https://github.com/Ezdh0K/TGuide.git
```

### 2. Переход в папку мобильного приложения

```bash
cd TGuide/TGuide
```

### 3. Установка зависимостей

```bash
npm install
```

### 4. Запуск проекта

```bash
npm start
```

Также можно использовать команду:

```bash
npx expo start
```

После запуска в терминале или браузере появится QR-код.

### Запуск на физическом Android-устройстве

1. Установите Expo Go.
2. Подключите телефон и компьютер к одной сети Wi-Fi.
3. Запустите проект командой `npm start`.
4. Отсканируйте QR-код через Expo Go.

Если подключение через локальную сеть не работает, запустите Expo в режиме туннеля:

```bash
npx expo start --tunnel
```

### Запуск на Android Emulator

```bash
npm run android
```

После запуска Expo также можно нажать клавишу `a` в терминале.

### Запуск веб-версии

```bash
npm run web
```

> Основной целевой платформой проекта является Android. Некоторые функции веб-версии могут работать иначе.

## Локальный запуск backend

Для обычного использования установленного APK локально запускать backend не требуется.

Backend запускается локально только при разработке и изменении серверной части проекта.

### Требования

* Node.js;
* npm;
* PostgreSQL.

### 1. Переход в папку backend

Из корня репозитория:

```bash
cd backend
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка переменных окружения

Создайте файл `.env` внутри папки `backend`.

Пример:

```env
PORT=3000

DB_HOST=localhost
DB_PORT=5432
DB_NAME=tguide
DB_USER=postgres
DB_PASSWORD=your_password

JWT_SECRET=your_secret_key
```

Настоящие пароли и секретные ключи нельзя добавлять в GitHub.

Для примера настроек рекомендуется создать файл `.env.example` без настоящих секретных данных.

### 4. Настройка базы данных

Создайте базу данных PostgreSQL и выполните SQL-скрипт:

```text
backend/src/database/Schema.sql
```

### 5. Запуск backend

В режиме разработки:

```bash
npm run dev
```

Обычный запуск:

```bash
npm start
```

## Подключение приложения к локальному backend

По умолчанию мобильное приложение использует backend, развёрнутый в интернете.

Чтобы подключить приложение к локальному серверу, измените адрес API в файлах папки:

```text
TGuide/services/
```

Пример адреса локального сервера:

```javascript
const API_URL = 'http://192.168.1.100:3000/api';
```

При запуске приложения на физическом телефоне нельзя использовать адрес `localhost`, поскольку он будет указывать на сам телефон.

Вместо `localhost` необходимо указать локальный IP-адрес компьютера. Телефон и компьютер при этом должны находиться в одной сети.
